# CS321M Predictive Evaluation Challenge

## Method Summary

Content-based Neural Collaborative Filtering (NCF) with online Platt scaling for cold-start prediction on AI evaluation benchmarks.

**Pipeline:**
1. **Stage 1 (Rasch IRT):** Joint MLE estimates subject ability (theta) and item difficulty (beta) from the training response matrix.
2. **Stage 2 (NCF):** Sentence Transformer (`all-mpnet-base-v2`, 768-dim) encodes `subject_content` and `item_content`; a condition embedding table (216 conditions x 32-dim) captures test conditions; an MLP head ([768x2 + 32] -> 256 -> 256 -> 1) predicts logits.
3. **Stage 3 (Online Calibration):** Platt temperature scaling fitted on labeled data each round via grid search over [0.2, 5.0] with 200 points. Falls back to T=1.0 if calibration does not improve NLL.

**Acquisition Function:** Greedy farthest-point diversity sampling in embedding space. No pre-fit centroids needed.

## Submission Files (Codabench ZIP)

| File | Description |
|------|-------------|

| `labeling.py` | Optional. `acquisition_function(input) -> float` |
| `models.txt` | Declares `sentence-transformers/all-mpnet-base-v2` for platform pre-fetch |

## How to Reproduce

```bash
# 1. Install dependencies
pip install datasets pandas matplotlib seaborn numpy torch scikit-learn sentence-transformers

# 2. Download data and run EDA
python 01_download_and_eda.py

# 3. Train model (outputs to models/)
python 02_train_model.py

# 4. Package submission ZIP
python 03_create_submission.py

# 5. (Optional) Local K-fold cold-start validation
python 04_local_validation.py --folds 3 --n-labeled 25 --n-eval 500
```

## Training Data

Public HuggingFace dataset: `aims-foundations/measurement-db`. We excluded `ultrafeedback` and `mt_bench` benchmarks due to non-binary response distributions. Final training set: 909 subjects, 70,873 items, 216 conditions.

## Key Design Decisions

- **Model selection by NLL** (not accuracy) to directly optimize the competition metric.
- **Embedding cache** (LRU, capacity 2000) prevents Codabench timeout by avoiding redundant Sentence Transformer calls.
- **Probability clipping** to [0.01, 0.99] avoids extreme log-loss penalties.
- **Error fallback** in `predict()`: returns labeled base rate on any exception.
- **BatchNorm1d** used during training; `NCF.eval()` at inference ensures correct behavior with single-sample inputs.
- **NaN/Inf safety** in `acquisition_function()`: returns 0.0 on non-finite scores to prevent platform fallback.
